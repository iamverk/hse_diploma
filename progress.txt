## Discovered Patterns
- Atomic stories (1 domain, 1 level) prevent timeouts
- check_edge.py --batch is faster than individual calls
- Wu-Palmer CSC has ceiling for domains with poor WordNet coverage (Pet Products, Cosmetics)
- NEVER create wrapper/grouping nodes (Retail Goods, Consumer Products, etc.) — kills CSC
- Keep L1 domains flat under root — 8-12 direct children of root
- Max 3-5 greps for product discovery, then add nodes
- Max depth 4: root → L1 → L2 → L3 (L4 only if needed)
- CLI add-node produces output that keeps watchdog happy
- Batch edge checks help catch weak names early (e.g., “Home Entertainment” under Electronics)
